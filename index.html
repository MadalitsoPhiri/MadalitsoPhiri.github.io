Map Estates uses the same platform as a property marketplace where agencies list and manage properties on the map. I'm one of two core developers on the backend and web apps, and I also work on the mobile apps.

What I built

The platform began as one backend and one web app serving every product. I split it into separate apps for water, waste and real estate. I also tightened the auth and token refresh flow, sped up the heaviest list endpoints, seeded the Playwright end-to-end test server, and wrote the developer guide new engineers start from.
